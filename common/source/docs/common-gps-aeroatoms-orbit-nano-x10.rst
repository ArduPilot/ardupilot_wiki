Overview
========

The **AeroAtoms Orbit Nano X10** is an ultra-compact dual-band GNSS navigation
module designed for ArduPilot-compatible vehicles. It integrates the u-blox
NEO-F10N dual-band GNSS receiver and IST8310 magnetometer, providing reliable
positioning for multirotors, fixed-wing aircraft, VTOLs, and ground vehicles.

Orbit Nano X10 supports concurrent reception of GPS, Galileo, BeiDou, QZSS,
and NavIC constellations with L1/L5 dual-band reception. The integrated LNA and
SAW filter improve signal reception and multipath mitigation, making the module
well suited for operation in challenging environments.

Key Capabilities
================

* Ultra-compact 28 × 28 mm form factor
* u-blox NEO-F10N dual-band GNSS receiver
* Concurrent reception of GPS, Galileo, BeiDou, QZSS and NavIC
* L1/L5 dual-band GNSS reception
* NavIC support
* Integrated LNA + SAW filter
* Integrated IST8310 magnetometer
* UART communication interface
* Navigation update rate up to 10 Hz
