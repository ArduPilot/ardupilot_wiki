========================
AeroAtoms Orbit Nano X9

.. image:: ../../../images/aeroatoms/orbit-nano-x9/orbit-nano-x9.png
   :align: center
   :width: 350px

Overview
========

The **AeroAtoms Orbit Nano X9** is an ultra-compact GNSS navigation module
designed for ArduPilot-compatible vehicles. It integrates the u-blox NEO-M9N
GNSS receiver and IST8310 magnetometer, providing reliable positioning for
multirotors, fixed-wing aircraft, VTOLs, and ground vehicles.

Orbit Nano X9 supports concurrent reception of GPS, Galileo, BeiDou, and
GLONASS constellations while utilizing an integrated LNA and SAW filter for
enhanced signal reception and improved interference rejection.

Key Capabilities
================

* Ultra-compact 28 × 28 mm form factor
* u-blox NEO-M9N multi-constellation GNSS receiver
* Concurrent reception of GPS, Galileo, BeiDou and GLONASS
* Integrated LNA + SAW filter
* Integrated IST8310 magnetometer
* UART communication interface
* Navigation update rate up to 10 Hz
* Low power consumption (<50 mA)
